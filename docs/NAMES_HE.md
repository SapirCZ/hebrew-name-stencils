# יצירת שבלונת שם

1. להתקין Python 3.11 ומעלה ולחלץ את החבילה.
2. מתוך תיקיית הפרויקט להריץ את שלוש פקודות ההתקנה והפתיחה שב־README.
3. בטופס להזין שם בעברית. אפשר שם כפול עם רווח. לבחור עובי ולהוריד את ה־ZIP.
4. לחלץ ולהסתכל ב־`preview.png`; האות הראשונה צריכה להיות מימין.
5. לפתוח `DUAL_COLOR.3mf` או `SINGLE_COLOR.3mf` כ־Open Project ב־Bambu Studio.
6. להתאים ציוד וחומרים, לבצע Slice ולבדוק את השכבות והסימונים לפני הדפסה.

אפשר להריץ ישירות:

```sh
.venv/bin/python src/stencils.py --name "נגה" --output my-stencil
```

אפשר להחליף את השם, להוסיף `--thickness 2.4`, ולבחור תיקיית פלט חדשה.
להרצה שאינה פותחת דפדפן אוטומטית: `.venv/bin/python src/name_app.py --no-browser`.
הכתובת היא `http://127.0.0.1:8765`. לסיום Ctrl+C בחלון שבו הופעל המחולל.

## קבצי התוצאה

| קובץ | שימוש |
|---|---|
| `DUAL_COLOR.3mf` | פרויקט עם גוף וסימונים משויכים לשני פילמנטים |
| `SINGLE_COLOR.3mf` | פרויקט עם גוף וסימונים שקועים, לצבע אחד |
| `single.stl` | אותו גוף שקוע, לסלייסר אחר |
| `body.stl`, `markers.stl` | חלקים נפרדים לייבוא כאובייקט מרובה חלקים |
| `preview.png` | תצוגת הפתח והסימונים |
| `model.json` | מידות, מיקום האותיות ותוצאות בדיקות הגאומטריה |
| `PRINT_HE.txt` | הוראות המלוות את הדגם |

לא להפוך או לשקף את האותיות. בייבוא שני STL לא לתת לסלייסר למרכז או להניח כל חלק בנפרד:
הסימונים חייבים להישאר במיקום ובגובה המקוריים. פתיחת ה־3MF עדיפה למטרה זו.

השבלונה שומרת על גודל האותיות ואינה מכווצת אוטומטית שם ארוך. רוחב מעל 240 מ״מ נדחה.
המחולל שומר אותיות סופיות כפי שהוקלדו. ניקוד, מקפים, גרשיים ואותיות בשפות אחרות אינם נתמכים כרגע.
